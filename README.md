# Site de l'ONG KINA

- Les textes du site sont dans `content/site.json`. Ils se modifient sans coder depuis **https://app.pagescms.org** (connexion avec ce compte GitHub).
- Les images sont dans `images/`.
- À chaque enregistrement, GitHub reconstruit et publie automatiquement le site (`node build.js`, voir `.github/workflows/deploy.yml`).
